# 🃏 Chaukdi Game

## 📌 Overview
Chaukdi (also known as "Teri") is a **multiplayer card game** that is more strategic and complex than CallBreak. This game provides an engaging and competitive environment, offering both **team-based** and **individual** gameplay modes. The game features an intuitive **Qt-based UI** and a **high-performance C++ server** for seamless multiplayer interactions.

## 🚀 Features

### 🎮 **Gameplay Features:**
- **🆚 Multiplayer Mode:** Supports up to **12 players** in a single session.
- **🤝 Two Game Modes:**
  - **Team Mode** – Play in coordinated teams.
  - **Individual Mode** – Compete solo against other players.
- **✅ Auto-Correct Card Selection:** Helps players make the best possible moves.
- **🎲 Strategic & Competitive Gameplay:** More complex than CallBreak, requiring skill and planning.
- **🔄 Known by Multiple Names:** Also called **"Chaukdi"** and **"Teri."**

### ⚙️ **Technical Features:**
- **📌 User Interface (UI):** Developed using **Qt** for an interactive and engaging experience.
- **⚡ Server:** Built with **C++**, ensuring high performance and stability.
- **🌐 Seamless Multiplayer Experience:** Handles real-time communication and interactions efficiently.



## 🛠️ Tech Stack
- **Frontend (Game UI):** Qt Framework
- **Backend (Server):** C++
- **Networking:** Socket Programming (TCP/UDP)
